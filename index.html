AnyHelpNow · Germany · Aug–Nov 2026

An AI voice agent that calls real businesses

Problem
An AI that calls German service providers must not invent names or e-mail addresses, and must never leave someone on a silent dead call.
What I built
The outbound voice agent end to end: the Python voice relay, a fallback to a second voice provider, and code-level checks on what the agent may read back. Around it, the call flow and audit trail in NestJS and Postgres.
Front end
The Next.js / React product on top of the NestJS services. I shipped across the full monorepo, front to back.
DevOps
A merge train was the only path into develop, with gated GitLab CI deploys from one host to separate beta and production stacks.
Tech
TypeScript · NestJS · Prisma/PostgreSQL · Redis + BullMQ · Socket.IO · Meilisearch · Next.js / React · Python (LiveKit, Gemini Live) · Docker Compose · GitLab CI
Result
The checks eliminated a recurring class of invented contact data. Every call was logged before dialling, so every outcome was accounted for.
